Verify an asset

Drop in any delivered asset or a manifest. This reads the Genblaze manifest — from inside the media file where one is embedded — and checks its signature and canonical hash against the recorded run.

This is the whole disclosure argument in one operation: the record of which model made a clip, from which prompt, for which release, travels inside the file. It cannot be quietly stripped without this check failing.

What a pass means

The manifest's signature and canonical hash match the run that produced it — so the provider, model, and prompt recorded against this asset are the ones that actually made it.

A fail is not necessarily tampering. An asset re-encoded by a social platform loses its embedded manifest, which is a known limit of embedding rather than evidence of a forged claim.
