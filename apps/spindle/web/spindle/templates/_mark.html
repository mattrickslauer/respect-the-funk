{# ============================================================================= _mark.html — the Spindle mark: a record read as a spectrum ============================================================================= This is the mark from the README and the repository's social preview (`docs/brand/thumbnail.svg`), on the page. Until 2026-08-15 the site drew a different thing — `_logo.html`, a wooden top, mid-spin — on the argument that a spindle is also the peg a top spins on and that a turning top says "the fleet is up" where a still record says "catalogue". The argument was fine and the outcome was not: the repository, the social card and the deck showed a record, the site showed a top, and a product with two logos has none. The record wins because it is the one already committed as a raster in three places outside this app. `_logo.html` was deleted in the same commit; `git show f1c8cdd:apps/spindle/web/spindle/templates/_logo.html` has it, and the geometry is worth reading before anyone re-draws it. Included, not a file, for the same reason `_design.html` is: there is no static mount in this app. See that file's header for the argument. ## The bars are not hand-authored The 64 radial bars below are pasted verbatim out of `docs/brand/thumbnail.svg`, which gets them from `docs/brand/mark.py` — three summed cosine harmonics, which is what makes the left half mirror the right. Nudging an individual `` here only makes that symmetry drift, and drifts it away from the PNG at the same time. To change the geometry: edit `mark.py`, re-run it, paste into the SVG, re-render the PNG, and paste the same group in here. Everything else on this mark is drawn. ## Two things changed on the way in, and only two **The colours are tokens.** `thumbnail.svg` hardcodes copper `#d97f4a`, which is exactly `--phosphor` on the lathe ground — the SVG has to, because a social card has no stylesheet. On the page it reads from `_design.html`, so the mark follows the ground it is dropped on instead of being a beige-on-beige hole in the manual. **This partial therefore only renders correctly on a surface that includes `_design.html`.** That is `landing.html`, `_public.html`, `_console.html` and `manual.html`. It is deliberately *not* `_layout.html`, which still carries its own wireframe-stage tokens and would resolve `var(--phosphor)` to nothing and paint the mark black. Do not include this there until that layout joins the design system. **The viewBox is cropped to the mark.** `thumbnail.svg` is 1280×640 of card, with the disc at (640, 274) and bars reaching r=165. The box below is the 330×330 square around exactly that, so the coordinates still match the source file rect for rect and a diff between the two is readable. ## The turn The bar field is the only asymmetric thing on the disc — every other element is a circle, so rotating them would be a no-op. So the animation is on the bars alone, and what it renders is the record turning. 48 seconds a revolution: a real 33⅓ is 1.8s and looks like a loading spinner at this size, which is a status, and this is a logo. `transform-box:view-box` is load-bearing — without it the origin resolves against the group's bounding box, which is not centred, because the bars differ in height. The inner `translate` stays an attribute and the rotation is CSS on the wrapper, so the two compose rather than the CSS replacing the attribute. `prefers-reduced-motion` stops it, and what remains is the mark exactly as the PNG draws it. ============================================================================= #}
