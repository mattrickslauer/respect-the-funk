spindlearchitecture · the control plane 17 agents · no orchestrator 3 / 5

The database is the scheduler, the queue and the message bus.

No agent calls another. An agent finishes by writing a row with a next_action_at, and that row is the message. Take the database away and the system does not slow down — it loses its control flow entirely.
Kill half the fleet mid-run: the lease expires and the row comes back. fleet.py · spend.py · agents.REGISTRY
spindlearchitecture · accountability the decision ledger and the replay 4 / 5

Why did the agent decide that, then?

The memory is alive: lessons accumulate, embeddings land, contact states move. By morning the world a decision was made in is gone. The ledger stores the exact logical timestamp, and the same query pointed at that timestamp returns the index as it stood — not a copy of it.
No audit table. No event log. No versioned copy of anything. 035_decision_ledger.sql · budgets.py
