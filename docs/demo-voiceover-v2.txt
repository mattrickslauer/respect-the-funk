Here's what runs it. AWS handles the logic. Backblaze B2 holds the bytes — and the proof.

That split is why this system has no database. A label stores documents, not rows — an artist, its measurements, a finished kit — so they live in a B2 bucket. Eleven services became five; idle cost, under a dollar a month.

B2 does four jobs.

It's the upload path — masters go browser straight to bucket, never touching our server.

It's the catalog. Every run writes under tenant, date, run ID.

It's the receipt. Every asset lands beside a manifest naming the provider, model and prompt behind every step. A kit that can't prove how it was made never reaches ready.

And it's the disclosure. Download a clip and that manifest travels inside the file, while the stored object stays byte-identical — so the hash still means something. Drop it into verify and it says exactly how it was made. Nothing is looked up. The proof is in the bytes.
